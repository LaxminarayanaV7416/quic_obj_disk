\section*{Project Proposal: Prism Store - An QUIC based Object Storage System}

\subsection*{Abstract}
This project proposes the design and implementation of a novel object storage kernel called PrismStore, 
specifically engineered to evaluate and optimize network protocol performance in distributed storage systems. 
The research aims to comprehensively analyze the impact of modern network protocols—HTTP/3 with QUIC, HTTP/2, 
and gRPC—on both client-server communication and inter-node coordination in object storage.
\begin{enumerate}
    \item \subsection*{Problem Statement}
        Current object storage systems predominantly rely on traditional HTTP/1.1 and HTTP/2 protocols for communication, potentially leaving significant performance 
        improvements unexploited. The performance of distributed storage systems heavily depends on network efficiency and I/O operations. 
        With the emergence of HTTP/3 (QUIC) and gRPC protocols, 
        there exists an opportunity to enhance storage system performance through strategic protocol selection and configuration.
    \item \subsection*{Primary Goal}
        Design and develop PrismStore, a custom object storage kernel that enables comprehensive evaluation of different network protocols' impact on 
        storage system performance.
    \item \subsection*{Secondary Objectives}
        \begin{itemize}
            \item Establish performance benchmarks against existing solutions (MinIO)
            \item Identify optimal protocol combinations for different communication channels
            \item Provide empirical evidence for protocol selection in distributed storage systems
            \item Develop a reference implementation for future object storage research
        \end{itemize}

    \item \subsection*{Technical Approach}

        \begin{itemize}
            \item \textbf{System Architecture}
        
                PrismStore will implement a distributed object storage system with configurable network protocols for two distinct communication channels:
                \begin{itemize}
                    \item Client-to-Server Communication: External client access to the storage system
                    \item Inter-Node Communication: Internal coordination between worker and master nodes
                \end{itemize}

            \item \textbf{Protocol Implementation}
        
                All protocols will be implemented with TLS 1.3 encryption to ensure security consistency across comparisons:
                    \begin{itemize}
                        \item HTTP/3 with QUIC: Modern protocol with built-in multiplexing and congestion control
                        \item HTTP/2: Multiplexed HTTP with server push capabilities
                        \item gRPC: High-performance RPC framework utilizing HTTP/2 transport
                    \end{itemize}
                    
            \item \textbf{Performance Evaluation Framework}
        
                The evaluation will systematically test protocol combinations across both communication channels, creating a comprehensive performance matrix.
        \end{itemize}

    \item \subsection*{Methodology}
    \begin{itemize}
        \item \textbf{ Phase 1: Core System Development}
        
        Develop the PrismStore kernel with modular network protocol support, ensuring consistent functionality across all protocol implementations.
        \item \textbf{ Phase 2: Baseline Establishment}
    
        Deploy PrismStore with HTTP/2 configuration and benchmark against MinIO object storage system to establish credibility and performance baselines.
        \item \textbf{ Phase 3: Protocol Evaluation}
            \begin{itemize}
                \item Step 1: Client Communication Analysis
                    Compare HTTP/2 vs. HTTP/3 for client-server interactions
                    Measure throughput, latency, and resource utilization

                \item Step 2: Inter-Node Communication Analysis
                    Evaluate protocol impact on worker-master node coordination
                    Assess scalability and fault tolerance characteristics

                \item Step 3: Cross-Protocol Evaluation
                    Test gRPC for both communication channels
                    Analyze performance against HTTP-based protocols
            \end{itemize}

        \item \textbf{ Phase 4: Optimization and Configuration Selection}
    
            Systematically evaluate all possible protocol combinations to identify the optimal configuration for different workload patterns and network conditions.
    \end{itemize}

    \item \subsection*{Expected Outcomes}
        \begin{itemize}
            \item \textbf {Research Contributions:} Comprehensive performance analysis of modern network protocols in object storage systems
            Empirical evidence for protocol selection guidelines in distributed storage architectures
            Open-source PrismStore implementation as a research platform
            \item \textbf {Performance Insights:} Quantitative comparison of protocol efficiency in storage workloads
            Identification of optimal protocol combinations for different use cases
            Network overhead analysis and resource utilization patterns
            \item \textbf {Practical Impact:} Performance optimization strategies for existing object storage deployments
            Protocol selection framework for storage system architects
            Reference implementation for educational and research purposes
        \end{itemize}

    \item \subsection*{Evaluation Metrics}
        Primary Metrics
        \begin{itemize}
            \item Throughput: Data transfer rates for upload/download operations
            \item Latency: Response times for storage operations
            \item Scalability: Performance degradation with increasing node count
            \item Resource Utilization: CPU, memory, and network resource consumption
        \end{itemize}
        Secondary Metrics
        \begin{itemize}
            \item Connection Overhead: Protocol establishment and maintenance costs
            \item Error Recovery: Performance under network failure conditions
            \item Concurrent Operations: Multi-client access patterns
        \end{itemize}

    \item \subsection*{Timeline and Deliverables}
        The project will deliver a complete PrismStore implementation with comprehensive performance evaluation results, demonstrating the impact of network protocol 
        selection on distributed object storage system performance. 
        The final system configuration will represent the optimal protocol combination identified through systematic evaluation.
    \item \subsection*{Significance}
        This research addresses a critical gap in understanding how modern network protocols can enhance distributed storage system performance. 
        By providing empirical evidence and a reference implementation, 
        the project will contribute valuable insights to both academic research and industry practice in distributed systems architecture.
\end{enumerate}
